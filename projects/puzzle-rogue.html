Puzzle Rogue

🗓 制作：2024年4月 • 🔄 最終更新：2024年4月
ゲーム パズル ローグライク React JavaScript

📖 制作物について

ブラウザで遊べるパズル×ローグライク要素を掛け合わせたオリジナルゲームです。 コンボを繋げることで強力なトークンを獲得し、ランダムに生成されるダンジョンを攻略していきます。

Reactを使用してSPA構成で実装しており、ゲーム状態はlocalStorageを利用して ブラウザ上で管理されます。

🛠 使用技術

  • React 18 (Vite)
  • Tailwind CSS
  • JavaScript (ES2022)
  • localStorage
