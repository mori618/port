📖 制作物について

ブランコを使って飛距離を競うブランコ飛距離チャレンジゲームです。 ブランコが最高点に達した瞬間が飛ぶベストタイミング！タイミングよく手を離して最高記録を更新しましょう。

操作はシンプルですが、ブランコの振り子の物理挙動をしっかり意識する必要があります。 カジュアルに遊べながらも、高い記録を狙うのに熱中できる一作です。

🕹 遊び方

  1. 1 ブランコが勢いよく揺れるのを待つ
  2. 2 最高点に達したタイミングでクリック（タップ）して手を離す
  3. 3 飛距離を記録して最高スコアを目指す！

🛠 使用技術

  • JavaScript (Vanilla)
  • HTML5 / CSS3
  • GitHub Pages（ホスティング）
