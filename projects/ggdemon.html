⚔️ GG Demon - Battle Charge

🗓 制作：2024年12月
ゲーム ターン制 ストラテジー JavaScript

📖 制作物について

エネルギー管理と読み合いが鍵となるターン制戦略バトルゲームです。 チャージ・攻撃・ガードを駆使し、敵の行動を予測しながら戦略的に立ち回ります。

タワーモードではHPを引き継ぎながら階層を登るサバイバル形式。 宝箱から強力なスキルを獲得し、ビルドを強化して深層を攻略していきます。

🗼 タワーモード

EASY 残機3・敵が弱め。はじめての方向け。
NORMAL 残機2・通常難易度のバランス設定。
HARD 残機1・高難易度。レアスキルが出やすい！

✨ 主な特徴

  • ▸ ダブル・デッキシステム：偏りのない多種多様な敵が出現
  • ▸ 難易度スケーリング：階層が深くなるほど敵が強化される
  • ▸ スキル獲得：宝箱・ミミック・ボス撃破で強力なスキルを入手
  • ▸ リザルト画面：倒した敵・使用スキル・到達フロアをまとめて確認
  • ▸ 25階層ループ：5階層ごとにボスが登場する周回設計

🛠 使用技術

  • JavaScript (Vanilla)
  • HTML5 / CSS3
  • GitHub Pages（ホスティング）
